# EMPLAY サイト全体デザイン方針

作成日: 2026-09-01  
対象: ブログを除く `emplay.jp` のコーポレートサイト

## 基準案

TOPページのA1を基準に、全ページを以下の表現へ統一する。

- 白を主背景とし、濃紺の文字・罫線で企業としての信頼感をつくる
- コバルトブルーとシアンを情報整理、赤を主要CTAに限定して使う
- アイソメトリック図解は同じ線・配色を維持し、ページごとに構図とモチーフを変える
- 大きな角丸、装飾的なグラデーション、カードの連続、写真への暗いオーバーレイを使わない
- 見出し、本文、比較情報、CTAの優先順位を罫線と余白で明確にする
- 実績値や顧客ロゴは、公開可能な根拠と許諾が得られるまで掲載しない
- 事例ページは今回の対象に含めない
- 助成金・補助金をサービス訴求へ掲載しない。一般的・中立的なブログ記事は対象外

## 共通デザインシステム

### カラー

| 用途 | 色 |
| --- | --- |
| 本文・見出し | `#0c1729` |
| 濃色セクション | `#061628` / `#08233f` |
| 情報アクセント | `#1358d8` |
| 補助アクセント | `#37bfd0` |
| 主要CTA | `#df2f4f` |
| 薄背景 | `#f3f6f8` |
| 罫線 | `#d8dee6` |

### レイアウト

- 本文幅: 最大1,180px
- ビジュアルを含む領域: 最大1,320px
- デスクトップの基本セクション余白: 92px
- モバイルの基本セクション余白: 66px
- ヒーロー: 全面ビジュアルの上に左寄せテキスト。分割カードにはしない
- 見出し: 日本語を主役にし、英語ラベルは11px前後の補助情報として扱う
- 反復情報: 罫線で構造化し、カードの多用を避ける
- CTA: 主CTAは赤、補助CTAは白地に濃紺罫線

### 共通コンポーネント

1. 白背景のグローバルヘッダー
2. 左にテキスト、右側に図解を置くページヒーロー
3. パンくず
4. 英語ラベル + 日本語見出し + 説明文のセクション見出し
5. 罫線型の比較・特徴・FAQ
6. 薄いグレー背景の問い合わせバンド
7. 濃紺フッター

## 本番実装の推奨順

1. 共通トークン、ヘッダー、フッター、CTA
2. TOPとサービス一覧
3. 4つのサービス詳細
4. 会社概要とお問い合わせ
5. 採用、ニュース、規約、サイトマップ
6. 1440px、768px、390pxでの表示確認とアクセシビリティ確認

この順序にすると、問い合わせに直結するページから先に統一でき、共通部品の変更を後続ページへ再利用できる。

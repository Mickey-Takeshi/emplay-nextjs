# EMPLAY コーポレートサイト競合調査とTOPデザイン方針

調査日: 2026-08-31  
対象範囲: ブログを除くコーポレートサイト、TOPページの情報設計とビジュアル表現

## 調査対象

| 企業 | TOPで強い要素 | EMPLAYへの示唆 |
| --- | --- | --- |
| [才流](https://sairu.co.jp/) | 研究会、知見、事例をファーストビュー直後に配置し、専門家集団としての信頼を先に形成 | 実績事例を使わない場合も、支援思想と専門領域をサービス説明より先に示す |
| [ベイジ](https://baigie.me/) | 「コンサル型ウェブ制作会社」という明快な立ち位置、サービス別CTA、顧客ロゴ、満足度 | EMPLAYは「制作・集客・CRM・AIを横断する実行パートナー」を一文で定義する |
| [LIG](https://liginc.co.jp/) | Web制作だけでなくDX・システム開発・教育を企業の活動や人とともに提示 | サービスの多さをカードで並べるだけでなく、一つの会社としての思想で束ねる |
| [キーワードマーケティング](https://www.kwm.co.jp/) | 独自メソッドを図解し、広告運用の仕組みと支援価値を可視化 | 「課題整理→制作・導入→運用・改善」の進め方を視覚的な中心要素にする |
| [ホットリンク](https://www.hottolink.co.jp/) | 利用目的別CTA、独自データ・メソッド、サービスと企業情報を明確に分離 | 「相談」「支援内容」「AI研修」を目的別に迷わず選べる導線にする |

## 現行TOPの評価

### 維持する点

- 「Web制作・集客・AI活用を、実行と改善まで。」は支援範囲と伴走性が伝わる。
- HP制作、クリエイティブ、広告、CRM、AI ACADEMYの5領域は過不足がない。
- 初回相談とサービス一覧の2CTAは、訪問者の温度差に対応できる。
- 強み、FAQ、会社・お問い合わせへの導線は揃っている。

### 改善する点

- ファーストビューの暗い青色オーバーレイが強く、人物や業務の実在感が弱い。
- サービス以降にカードが連続し、情報の重要度が同じに見える。
- 企業としての考え方、進め方、会社情報がサービス説明より後ろにあり、信頼形成が遅い。
- HP制作、広告、CRM、研修の関係性が分からず、「何を頼めばいいか分からない」人に選択負荷がある。
- ブログを除くと、専門性を示すコンテンツが強み3項目だけに集約されている。

## 3つのデザイン方向

### Concept A: Corporate Confidence

対象: 発注先の安定性、分かりやすさ、社内稟議の通しやすさを重視する中小企業  
表現: ネイビー、白、赤の抑制された企業デザイン。大きな実写と罫線で信頼感を作る。  
構造: ヒーロー → 対応条件 → 支援思想 → サービス → 強み → 進め方 → AI研修 → 相談

### Concept B: Business Operating System

対象: Web、広告、CRM、AIを横断して事業課題を解決したい経営・マーケティング担当者  
表現: 深いグリーン、ティール、コーラル。都市と業務システムの印象で先進性を出す。  
構造: ヒーロー → EMPLAYの立ち位置 → 5領域 → 課題解決プロセス → 支援原則 → AI研修 → 相談

### Concept C: Human Partnership

対象: 外注先との距離感、相談しやすさ、伴走性を重視する経営者  
表現: チャコール、生成り、深緑、赤茶。人物写真と明朝見出しで人間味と品質感を出す。  
構造: ヒーロー → ミッション → サービス → 相談姿勢 → 約束 → 進め方 → AI研修 → 相談

## 共通の実装原則

1. ヒーローは実写を全面に使い、サービス内容と主要CTAを1画面で理解できるようにする。
2. 実績数字や顧客ロゴは、根拠と掲載許諾が得られるまで使わない。
3. 事例は今回の要件どおり構成に含めない。
4. ブログはTOPリニューアルの対象外とし、主要導線には置かない。
5. HP制作の初期費用は45万円からとし、他サービスの料金は要問い合わせのまま扱う。
6. AI ACADEMYは独立サービスとして見せ、AI/DX研修と重複する名称を置かない。
7. 助成金・補助金は営業訴求やサービス説明へ記載しない。
8. モバイルではCTA、見出し、サービス名が画面幅内に収まる固定寸法を設定する。

# 追加コンテンツ計画（2026-09-02）10本

`docs/seo-audit-2026-09-02.md` の監査結果にもとづく。作成基準は `docs/blog-content-creation-guide.md` に従う。

## 1. なぜこの10本か

監査で分かった構造上の弱点は「記事はあるが、サービスページを支える形になっていない」ことだった。

- ブログ→サービスのリンクは122記事あるのに、**サービス→ブログの逆流がほぼゼロ**
- 294本の大半が Know 意図（調べる段階）で、**発注直前の Compare / Do 意図の層が薄い**
- `/service/creative` に対応するカテゴリが存在せず、CTAからのリンクが出ない

そこで今回は**「発注の直前に読まれる記事」を4つの収益ページごとに置く**方針とした。
記事数を増やすこと自体は目的にしない。

## 2. 既存記事との重複チェック（実施済み）

候補15本を全294記事とタイトル・本文で機械照合し、2本を落とした。

| 落とした候補 | 理由 |
|---|---|
| CRMが定着しない原因と立て直し方 | `crm-implementation-cost-guide`（タイトルに「定着のコツ」）と検索意図が重なる |
| GA4キーイベントの設定手順 | `google-ads-conversion-setup`（GTM連携・拡張CVまで解説）と重なる |
| 競合調査の進め方 | `competitor-website-analysis-guide` が「本当の競合の見つけ方／調べる7項目／無料ツール比較／手順／改善アクションへの変換」を全て網羅していた。**執筆開始後に見出し構成まで確認して判明したため、Googleショッピング広告・Merchant Centerの設定（既存との重なりゼロを機械照合で確認）へ差し替えた。** |

残した中で既存記事と近いものは、**ピラー記事の下に置く詳細記事**として位置づけ、相互リンクする。

| 新規記事 | ピラー記事 | 切り分け |
|---|---|---|
| 表示速度の改善手順 | `seo-technical-optimization-guide`（Core Web Vitalsは12個のH2のうち1つ） | 新規はLCP/INP/CLSの原因特定と修正手順に限定 |
| 写真と原稿の準備 | `web-production-company-selection`（「発注前の社内準備」は1セクション） | 新規は撮影費用・原稿分担・素材の権利に限定 |
| ECサイトのSEO | `ec-sales-improvement-guide`（集客施策全般。SEO専用の節はない） | 新規は商品/カテゴリページの設計と構造化データに限定 |

## 5. 記事の作成基準

`docs/blog-content-creation-guide.md` に従う。今回の監査結果を踏まえた上乗せは次の2点。

- **タイトルは28〜34字に収める。** 実際の `<title>` には「 | 株式会社EMPLAY」が10字付くため、
  ガイドの「30〜45字」の上限で書くと検索結果で必ず切れる（監査 §2-1）。
- **サムネイルは自社のローカルWebPを使う。** 既存294本はUnsplashのホットリンクだが、
  ガイド §9 は「原則ローカル管理のWebP」と定めており、監査 §2-7 でも指摘した。
  新規分から `public/images/renewal/` の自社イラストを割り当てる。

## 7. 公開結果（2026-09-02）

10本すべてを公開し、本番で実測確認した。記事数は294本 → **304本**（id 307〜316）。

### 品質の実測

| 指標 | 実測 | 基準 |
|---|---|---|
| 本文量 | 8,248〜9,782字 | 5,000〜8,000字（やや上振れ） |
| 平文比率 | 71.9〜89.1% | 45%以上 |
| タイトル本体 | 29〜33字 | 28〜34字 |
| excerpt | 106〜119字 | 100〜120字 |
| FAQ（`### 質問`形式） | 各4〜6問 | 構造化データ抽出用 |
| 本文のH1 / 不正slug / リンク切れ | 0 | 0 |
| 出典URL | 全件HTTP 200を実測 | 官公庁・製品公式のみ |

本番HTMLでの確認: 10本すべて HTTP 200 / 自己参照canonical / h1が1つ /
Article + BreadcrumbList の構造化データ / sitemap掲載（327URL）/ og:imageが自社ローカル画像。

### 検品で見つかり、公式ページで裏取りして修正した事実誤り

| 誤っていた記述 | 公式の記載 |
|---|---|
| Merchant Centerの画像は500×500px以上が必須 | 「新しい要件の適用は2027年1月31日に開始されます」＝将来要件。現行値は断定せず[商品データ仕様](https://support.google.com/merchants/answer/7052112?hl=ja)へ誘導する形へ変更 |
| ディスプレイ広告とデマンドジェネレーションは並立する選択肢 | 「ディスプレイ広告キャンペーンはデマンドジェネレーションに統合」「2026年6月：移行ツール」。移行期であることを本文に明記 |
| 自動アイテム更新に構造化データが必須 | 公式は「設定することをおすすめします」＝推奨 |
| メーカー許諾があればスパムに当たらない | 引用元ポリシーの判断基準は許諾の有無ではなく付加価値の有無 |

あわせて、出典のない順位断定（「つまずきやすいのは〜」）と根拠を示せない伝聞（アカウント停止）を削除した。

**逆に、検品の指摘2件は採用しなかった。**
- 「平文比率41.7%で基準未達」は行数で数えた結果。ガイドの定義は文字数であり、実測は79.6%。
- もう1件は現在の原稿に存在しないURLへの指摘だった。

### 残る課題

`<title>` は42〜46字で、日本語SERPの表示上限（約30〜32字）を依然として超えている。
記事タイトル本体は29〜33字に収めたが、テンプレートが付ける「 | 株式会社EMPLAY」で12字増えるため。
**これは記事側では解決できない。** 監査 §2-1 のとおり、サフィックスの方針をテンプレート側で見直す必要がある。
